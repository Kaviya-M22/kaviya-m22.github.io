# Kaviya M — Portfolio Website

A responsive personal portfolio website for an ECE student, designed with pink and lavender shades.

## Included
- `index.html` — portfolio structure/content
- `style.css` — responsive pink/lavender visual design
- `script.js` — animated 3D AI Rescue Rover using Three.js
- No profile photograph
- No phone number

## Run locally
Open `index.html` in a browser.

The 3D model loads Three.js from a CDN, so an internet connection is needed for the 3D scene unless Three.js is downloaded locally.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and open the generated GitHub Pages URL.

Replace the email address or add links as needed.
