# Kaviya M — K-Explorer Portfolio

Responsive ECE portfolio with a custom Three.js 3D explorer robot inspired by the supplied reference.

- Pink/lavender/cyan metallic robot
- Rounded rectangular display head
- Mechanical arms and legs
- Interactive drag-to-rotate and wheel-to-zoom
- Custom K + explorer orbit logo
- No text underlines
- IEEE research paper and DOI included

Open `index.html` in a browser. Three.js is loaded from jsDelivr.
